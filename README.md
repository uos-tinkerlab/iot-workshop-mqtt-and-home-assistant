# IOT Workshop - Breadboards, Microcontrollers and MQTT  

Welcome! By the end of this workshop you will have created a WiFi-connected smart sensor and smart devices.
   
By the end of this workshop, you'll have built a simple light sensor that wirelessly controls the brightness of LEDs on another device.

No previous electronics experience is needed. We'll start with the basics and build up to something that you can comfortably tinker with yourself.

Please read everything carefully. If you need any help, let us know :D

### Learning Aims

In this workshop, you'll learn how to:
- Build basic electronics circuits: understanding breadboards, LEDs, resistors, sensors, and how they connect to the Raspberry Pi Pico
- Control hardware with MicroPython: this is an excellent tool enabling you to use code to read sensor and control output pins to devices like LEDs
- Connect devices over a network: the foundations of IoT, you'll understand how Wi-Fi and MQTT allow devices to communicate wirelessly

### Workshop Structure

Stages 01-05 are guided walkthroughs. Here you'll get introduced to the hardware, programming, and the networking concepts you need to get tinkering on your own. You'll start independently on your own activities, and then eventually connect your device with a partner.

Stage 06 is where you get to experiment. We've provided a bunch of challenges, from simple mods to more complicated projects. You can choose whichever interests you most or come up with your own challenges (we'd love if you shared your ideas with us!)
